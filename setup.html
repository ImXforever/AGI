Zenovix 1.6.0راهنمای اولین راه‌اندازی اکوسیستم

اولین بار اکوسیستم زنوویکس را روشن می‌کنید

زنوویکس یک مدیر عملیات دیجیتال برای یک شرکت است (یک استقرار Railway). پیام مشتری را می‌گیرد، از دانش شرکت جواب می‌دهد، پیش‌فاکتور و تیکت می‌سازد، و قبل از کار حساس از مدیر اجازه می‌گیرد. شرکت خودران نیست، تبلیغ نمی‌خرد، پول جابه‌جا نمی‌کند.

سه سطح که بعد از ستاپ می‌بینید

  1. / سایت عمومی انگلیسی — بدون دکمه Login
  2. /app مینی‌اپ مشتری در تلگرام
  3. /admin/ops/ecosystem.html پنل مدیر — اول اکوسیستم سه‌بعدی

قبل از شروع این‌ها را آماده کنید

  • حساب Railway + افزونه Postgres + افزونه Redis
  • ربات تلگرام از BotFather
  • باکت Cloudflare R2 یا S3 سازگار
  • کلید LLM (مثلاً OpenRouter یا 9router خودتان)

۱. پروژه Railway و دیتابیس

بدون این چهار مورد اپ بوت نمی‌شود. Postgres و Redis را از پلاگین Railway بگیرید، خودتان نسازید.

۲. هویت شرکت (Tenant)

یک استقرار = یک شرکت. این نام‌ها در گزارش‌ها و تماس پشتیبانی دیده می‌شوند.

۳. تلگرام — کانال اصلی

تلگرام اجباری است. سکرت وب‌هوک را خودتان بسازید و همان را به setWebhook بدهید. زنوویکس این سکرت را اختراع نمی‌کند.

از کجا بیاورید

  1. در تلگرام به @BotFather بروید → /newbot → توکن را کپی کنید.
  2. آیدی عددی مدیر: به @userinfobot پیام بدهید. چند مدیر را با ویرگول جدا کنید.
  3. سکرت وب‌هوک: یک رشته تصادفی حداقل ۱۶ کاراکتر (مثلاً خروجی openssl rand -hex 16).

۴. ورود مدیر به پنل

بعد از لاگین باید مستقیم اکوسیستم سه‌بعدی باز شود. WEB_SECRET کوکی نشست را امضا می‌کند.

۵. مدل زبانی

حالت پیشنهادی: LLM_MODE=direct به یک API سازگار با OpenAI. اگر DIRECT خالی باشد و OPENAI پر باشد، همان استفاده می‌شود.

۶. فضای فایل (R2 / S3)

پیوست، بکاپ pg_dump، پیش‌فاکتور و گزارش اینجا ذخیره می‌شود. از پنل Cloudflare R2 یا هر S3 سازگار (مثل t3.storageapi.dev) کلید بگیرید.

۷. تأیید انسان (HITL)

خودکار: خواندن ایمیل معمولی، لید، تیکت، تسک، تقویم عادی. همیشه تأیید مدیر: ایمیل حساس، انتشار، پیش‌فاکتور، قیمت، پرداخت، قرارداد، حذف داده، تغییر دسترسی. ناشناخته = رد.

۸. کانال‌های اختیاری

تا وقتی ENABLED=false است، آن کانال خاموش است. واتساپ خاموش = پاسخ ۴۰۴ (نه ۲۰۰). اگر روشن کنید، سکرت خالی یعنی رد درخواست.

۹. برند، ساعت کاری، فروش

۱۰. حافظه، ناوگان، بکاپ

۱۱. وب‌هوک و چک‌لیست روشن شدن

بعد از اینکه دامنه Railway آمد

  1. متغیرها را در Railway → Variables → RAW Editor بچسبانید.
  2. Deploy کنید. سلامت: GET /healthz
  3. وب‌هوک تلگرام (همان سکرت):

https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://YOUR_HOST/tg/webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>

  • ☐ /healthz برابر ok
  • ☐ / سایت انگلیسی بدون Login
  • ☐ لاگین مدیر → /admin/ops/ecosystem.html
  • ☐ پیام تست به ربات → در صف یا پاسخ
  • ☐ واتساپ اگر خاموش است روی /wa/webhook باید ۴۰۴ باشد

۱۲. فرهنگنامه همهٔ متغیرها

جستجو کنید. هر متغیر زنوویکس که از Railway ست می‌شود اینجاست.
